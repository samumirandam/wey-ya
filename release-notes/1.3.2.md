# Release notes — 1.3.2 (versionCode 8)

Notes for Play Console. One section per language (the 5 the app supports).
Play Store limit: **500 characters** per language. Copy the block and paste it into its field.

Technical summary (not shipped to Play): maintenance release bundling PRs #5, #6, #7 — screening timeout (fail-open) so call screening can't hang, `attemptThreshold` minimum raised to 2, DataStore reads degrade to defaults on IOException, blank `tel:` numbers treated as hidden, Room DB → v6 with indexes on the screening hot path, domain layer decoupled from Android/Room, and broad new test coverage. No new user-facing features. See `CHANGELOG.md`.

---
